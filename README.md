# Claude Text Editor Tool

A hands-on demonstration of Claude's built-in **text editor tool** via the Anthropic API. The notebook shows Claude autonomously editing source files — reading, modifying, and creating Python files through a structured tool-use loop.

## What This Project Does

The Jupyter notebook (`005_text_editor_tool.ipynb`) runs a conversation with Claude where it is given a task: write a pi-calculation function in `main.py` and then generate a test file `test.py`. Claude accomplishes this entirely through tool calls — no manual file editing.

The generated files (`main.py`, `test.py`) are the **output** of that agentic run, checked into the repo so you can see the end result.


## Key Concepts Demonstrated

### Text Editor Tool Schema
Claude's text editor is a built-in tool type — not a custom function. The schema version is model-dependent:

| Model | Tool type | Tool name |
|---|---|---|
| `claude-3-5-sonnet-*` | `text_editor_20241022` | `str_replace_editor` |
| `claude-3-7-sonnet-*` | `text_editor_20250124` | `str_replace_editor` |
| `claude-sonnet-4-5-*` | `text_editor_20250728` | `str_replace_based_edit_tool` |

### Supported Commands

| Command | Description |
|---|---|
| `view` | Read a file or list a directory; supports optional line range |
| `str_replace` | Replace a unique string in a file (fails on 0 or 2+ matches) |
| `create` | Create a new file with given content |
| `insert` | Insert text after a specific line number |
| `undo_edit` | Restore the file from the most recent `.backups/` snapshot |

### Agentic Loop

The conversation loop in the notebook drives the interaction:

```python
while True:
    response = chat(messages, tools=[get_text_edit_schema(model)])
    add_assistant_message(messages, response)

    if response.stop_reason != "tool_use":
        break

    tool_results = run_tools(response)
    add_user_message(messages, tool_results)
```

Claude keeps calling tools until it signals it is done (`stop_reason != "tool_use"`).

### Safety — Path Traversal Guard
`TextEditorTool` validates every path against a `base_dir` root so Claude cannot read or write outside the project directory:

```python
if not abs_path.startswith(self.base_dir):
    raise ValueError("Access denied: Path is outside the allowed directory")
```

## Setup

### Prerequisites
- Python 3.9+
- An [Anthropic API key](https://console.anthropic.com/)

### Install dependencies

```bash
pip install anthropic python-dotenv jupyter
```

### Configure your API key

Create a `.env` file in the project root:

```
ANTHROPIC_API_KEY=sk-ant-...
```

### Run the notebook

```bash
jupyter notebook 005_text_editor_tool.ipynb
```

Run all cells. Claude will call the text editor tool to write `main.py` and `test.py`.

### Run the generated tests

```bash
python test.py
```

Expected output:
```
Running tests for calculate_pi()...
✓ All tests passed! Pi calculated correctly to 5 decimal places.
✓ Pi is in the expected range.
✓ First 5 decimal digits are correct: 3.14159
```

## How the Pi Calculation Works

Claude chose **Machin's formula** for the implementation:

```
π/4 = 4·arctan(1/5) − arctan(1/239)
```

Each `arctan` is evaluated via a Taylor series. This formula converges much faster than a naive Leibniz series, reaching 5 accurate decimal places with far fewer terms.
